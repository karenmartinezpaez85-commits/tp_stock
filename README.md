# 📦 Sistema de Control de Stock - TP Integrador

## 📝 Descripción del Proyecto

Sistema web para la gestión integral de inventario de productos, desarrollado en PHP y MySQL siguiendo la arquitectura **MVC (Modelo-Vista-Controlador)**. 

El sistema permite el control de stock mediante movimientos de entrada, salida y ajustes, con **actualización automática del inventario** mediante transacciones de base de datos (ACID), y generación de reportes con filtros avanzados.

### 🎯 Objetivos del sistema
- Controlar el stock de productos en tiempo real.
- Registrar todos los movimientos de entrada y salida.
- Alertar cuando el stock esté por debajo del mínimo.
- Generar reportes estadísticos para la toma de decisiones.
- Diferenciar roles entre Administrador y Operador.

## 🛠️ Requisitos de Instalación

### Software necesario
- **XAMPP** (versión 8.x o superior) o **Laragon**
- **PHP** 8.0 o superior
- **MySQL** 5.7 o superior (incluido en XAMPP)
- **Navegador web** moderno (Chrome, Firefox, Edge)

### Extensiones de PHP requeridas
- PDO (PHP Data Objects)
- PDO_MySQL
- mbstring
